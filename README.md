# 北陸小隊 PWA · 皮克敏 × 寶可夢

本版將背景改為皮克敏花園，按鍵及卡片改用 20 種人氣寶可夢裝飾，保留既有資料、六個分頁與互動功能。角色名單、排名年份及官方素材來源請見 [ASSETS.md](ASSETS.md)。主題圖片均可離線顯示；快取版本已升為 v5。

以原有 `hokuriku_trip_app_v4_sakura.html` 為基礎，保留行程、行前準備、抵達日本、餐廳、購物、入境資料六個分頁。免建置、無第三方 CDN、無執行時依賴，支援 GitHub Pages 專案子路徑。

先看 [SYNC_SETUP.md](SYNC_SETUP.md)：建立 Supabase 專案、執行 cloud/setup.sql，三台裝置登入相同家庭帳號。同步程式已完成，但尚未連接真實雲端專案。App 開啟且有網路時每 5 秒檢查更新；離線變更會在重新連線後上傳。護照欄位不參與同步。

## 本機執行與測試

需要 Node.js 22 以上，不需要 npm install。

```sh
npm test
npm start
```

開啟 http://127.0.0.1:4173 。請使用 HTTP 預覽；直接點開 index.html 的 file:// 模式不會註冊 Service Worker。

## 先保留舊資料，再搬移

1. 在原本使用的瀏覽器中開啟舊 HTML，先按「匯出備份 JSON」，將檔案保存在私人位置。
2. 部署新版並開啟，選「匯入備份」，選擇剛才的 JSON。
3. 核對六個分頁、勾選狀態與護照欄位，再保留該備份。

儲存鍵維持 `hokuriku2026_v1`，清單項目、ID、未知擴充欄位及原有 JSON version 1 結構保留；載入不會自動新增接送待辦、不會寫入預設資料。使用者編輯、確認還原，以及啟用後的雲端同步會儲存內容。讀取或結構驗證失敗時會停止寫入，可用「匯出備份 JSON」下載原始內容供復原。

localStorage 依來源（協定、網域、連接埠）隔離。原本 file://、localhost、GitHub Pages、不同瀏覽器及 iOS 主畫面 App 的資料不保證互通，必須透過備份搬移。相同 GitHub Pages 網域下不同專案可能共用相同 localStorage 鍵；請避免在同一網域部署多份獨立旅程。本版可設定 Supabase 家庭帳號，在兩支 iPhone 與 iPad 間同步。

還原前會要求確認並下載目前資料的備份。請確認下載已保存；瀏覽器可能攔截下載。格式無效、重複 ID、非法日期及超過 5 MB 的檔案不會匯入。儲存額度不足會回復上一次成功儲存的記憶體狀態並提示錯誤。其他視窗修改資料時，本視窗會停止寫入，重新載入後再編輯。

## GitHub Pages 部署

1. 建立 GitHub 儲存庫，只放此資料夾內的交付檔案。**不要提交原始個人 HTML、JSON 備份或個人瀏覽器資料。** 公開程式使用空白護照欄位與「旅客 1–4」，沒有實際護照個資。
2. 將此資料夾內容放在儲存庫根目錄，包含 `.nojekyll`、icons、manifest.webmanifest、sw.js、index.html、app.js、styles.css、sync.js、sync-core.js、cloud-config.js 及 assets。README、tools、tests 可保留。
3. 在 GitHub 儲存庫 Settings → Pages 選 Deploy from a branch，選 `main` 與 `/ (root)`，儲存。
4. 等待 Pages 部署完成，開啟 `https://你的帳號.github.io/儲存庫名稱/`。若使用自訂網域，必須啟用 HTTPS。
5. 等畫面出現「離線快取已備妥」後，重新開啟一次再測試離線。

這些是部署步驟，本交付沒有建立遠端儲存庫或上傳任何個人資料。

## iPhone / iPad 與離線使用

- 使用 Safari 開啟 HTTPS 網址，分享 → 加入主畫面。圖示、啟動畫面色及安全區邊距已設定。
- 按住行程左側把手並移動即可拖曳；卡片其他區域可正常捲動。拖到畫面上緣／下緣會自動捲動，拖到日期標題可放進當天，拖到卡片上／下半可指定前後位置。取消指標操作不會保存移動。
- 也能在「編輯」中直接變更日期；桌面鍵盤聚焦把手後用 ↑／↓ 排序。
- 果凍動畫只套用於把手按下，減少畫面抖動；遵循系統「減少動態效果」。
- 首次連線完成快取後，六頁、編輯、清單、護照查看及 JSON 備份／還原可離線使用。Google Maps、官網與 Visit Japan Web 外部頁面需要網路，未快取外部內容。
- 快取只包含 App 靜態檔案；旅客填入的內容留在 localStorage；啟用同步後，五個清單會上傳私人雲端，護照仍留在本機。內容不會寫入 Service Worker 快取。資料仍是裝置端明文，請使用私人裝置。備份也可能包含完整個資。
- Safari 清除網站資料、私人瀏覽或系統儲存清理可能導致資料遺失；離線快取不是資料備份。

## 更新版本

修改靜態檔案後，必須將 sw.js 的 `PREFIX+'v5'` 升為 `v6`（之後遞增），一起部署。新 Service Worker 完整下載成功後才會安裝；不強制接管正在編輯的舊視窗。看到更新提示後，關閉所有此 App 的分頁及主畫面視窗再重開。啟用新版本會清除此部署範圍的舊 shell 快取，不會清除 localStorage。請勿隨意變更儲存鍵。
